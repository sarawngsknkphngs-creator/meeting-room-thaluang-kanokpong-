# 📅 ระบบจองห้องประชุมออนไลน์ (Smart Meeting Room Booking System)
### วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์

> "เทคโนโลยีดิจิทัล เพื่อการบริหารจัดการที่มีประสิทธิภาพของวิทยาลัยฯ"  
> **จองง่าย อนุมัติไว ใช้งานได้จริง ครบวงจรในระบบเดียว**

---

## 🌟 ฟีเจอร์เด่นของระบบ (Key Features)

1. **ปฏิทินสถานะห้องประชุม (FullCalendar View):**
   - แสดงตารางการจองแบบ รายวัน / รายสัปดาห์ / รายเดือน
   - แยกสีตามห้องประชุมหลักทั้ง 6 ห้องของวิทยาลัยฯ
   - คลิกช่องว่างเพื่อจองเวลาที่ต้องการได้ทันที

2. **ระบบตรวจสอบเวลาทับซ้อนแบบเรียลไทม์ (Conflict Detection):**
   - คำนวณช่วงเวลาแบบคณิตศาสตร์ ป้องกันการจองห้องซ้ำ 100%
   - รองรับการจองยาวต่อเนื่อง (1 ชม., 2 ชม., 4 ชม. ครึ่งวัน, หรือทั้งวัน)
   - แจ้งเตือนสีแดงทันทีหากมีผู้จองเวลาเดียวกัน

3. **ระบบอนุมัติตามลำดับขั้น (Multi-Level Approval Workflow 4 ขั้นตอน):**
   - **ขั้นที่ 1:** ผู้ขอใช้ยื่นแบบฟอร์ม (นายวสุภัทร กุลเมือง)
   - **ขั้นที่ 2:** เจ้าหน้าที่ศูนย์ดิจิทัลฯ ตรวจเช็คห้องและอุปกรณ์ (นายวัชรพงศ์ โสภา)
   - **ขั้นที่ 3:** หัวหน้างานศูนย์ดิจิทัลฯ รับรองคำขอ (นายเอกราช เขียวทอง)
   - **ขั้นที่ 4:** รองผู้อำนวยการฯ พิจารณาอนุมัติ/ไม่อนุมัติ (นายชาตรี เริงชัยภูมิ)

4. **ระบบรายงาน & พิมพ์แบบฟอร์มราชการ (Official A4 Print):**
   - สั่งพิมพ์แบบฟอร์มขอใช้ห้องประชุมและอุปกรณ์ขนาดกระดาษ A4 ตามระเบียบงานสารบรรณ
   - มีตราสัญลักษณ์สถานศึกษา และตารางลงนาม 4 ฝ่ายครบถ้วน
   - ส่งออกข้อมูลเป็นไฟล์ Excel / CSV (UTF-8 BOM ภาษาไทยไม่เพี้ยน)

5. **ระบบแจ้งเตือนแบบเรียลไทม์ (Real-Time Notifications):**
   - Notification Bell พร้อม Badge นับจำนวนรายการที่ยังไม่อ่าน
   - Toast แจ้งเตือนเด้งทันทีพร้อมเสียง Chime สังเคราะห์
   - รองรับการส่งข้อความเข้า LINE Notify และ HTML Email (พร้อมปุ่ม Add to Google Calendar)

---

## 🏢 ห้องประชุมหลักทั้ง 6 ห้อง

1. **หอประชุมศิริสาร** (รหัส `MR-SRS`, ความจุ 300 ที่นั่ง) - สีน้ำเงิน
2. **ห้องประชุมสักทอง** (รหัส `MR-STH`, ความจุ 50 ที่นั่ง) - สีส้ม
3. **ห้องประชุมหน้าห้องผู้อำนวยการ** (รหัส `MR-DIR`, ความจุ 20 ที่นั่ง) - สีม่วง
4. **ห้องประชุม (กาญจนา)** (รหัส `MR-KJN`, ความจุ 80 ที่นั่ง) - สีเขียว
5. **อาคารโดมอเนกประสงค์** (รหัส `MR-DOME`, ความจุ 500 ที่นั่ง) - สีเหลือง
6. **ห้องคอมพิวเตอร์กลาง (ห้องโสต)** (รหัส `MR-COMP`, ความจุ 40 ที่นั่ง) - สีฟ้าเทา

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### 1. เปิดดูทันทีผ่านเบราว์เซอร์ (Instant Preview)
- ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วย Google Chrome, Microsoft Edge หรือเบราว์เซอร์ใดก็ได้

### 2. รันระบบเต็มรูปแบบ (Full-Stack Next.js 15 + Prisma)
```bash
# ติดตั้ง dependencies
npm install

# รัน Development Server
npm run dev
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
